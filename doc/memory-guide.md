# 记忆操作指南

1. 在“会话”选择具体群或私聊，打开“记忆与暂存”。列表按层级展示内容、事实键与版本；“包含历史版本”可追溯已替代、删除和过期记录。
2. 点击“查看／编辑”，修改任意层并保存。草稿区显示“待短期整理”，原已发布内容继续生效。到期或点击“整理短期”后，更正进入短期；中期、长期各自在自己的整理时点吸收它。
3. “立即整理全部”按短→中→长执行。按钮提交异步任务，进度和错误通过整理状态表及运行记录查看。
4. 手工笔记直接创建即可，不需要关联聊天消息或标记重要。重要标记提高事实重要性，不改变整理时机。
5. 在“会话设置 → 记忆”配置间隔与保留期。默认会话编辑全局值；具体会话可取消“跟随全局记忆整理设置”并保存覆盖。普通人设、模型和聊天配置继续采用独立快照。
6. 修改冲突时先查看最新记录，撤销或处理旧草稿后重新提交。直接删除立即停止该事实的检索；历史不会物理清空。

主题入口在顶部，可选择亮色、暗色、跟随系统。界面轮询不会覆盖未保存草稿，离开编辑页面时会提示。
