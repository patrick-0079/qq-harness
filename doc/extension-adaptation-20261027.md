## 已验证的旧包工作流

| 包 | 已有证据 | 尚未覆盖的范围 |
|---|---|---|
| ccb-command | 原包经公共入站点消费指令、绑定运行发送、停用不残留 | 正式状态与旧数据导入 |

## 宿主边界与生命周期

旧包编译到独立操作员目录，不打包旧单体宿主。私有模块按公开服务适配；未知模块明确拒绝。编译保留来源 SHA，原项目保持只读。

已补充局部动态导入、`import.meta.dirname`、数据目录、实例内 globalThis、定时器、process 监听与网络取消。失败重载保留旧工具和旧入站处理，等待异步关闭后才切换新实例。原包的过时发送和 finish 说明只在源指令字面量与清单提示词上转换，聊天档案不改写。

迁移预览保存旧启停意图和配置快照；预览清单标记 `stage=preview`，宿主拒绝执行。待每包工作流验收、数据迁移与回滚完成后才能晋级。

最新预览有93包可生成入口、7包需要进一步适配，image-studio使用原生移植。该数字是编译清单，非完成率。7包为cross-memory、hell-joke、net-proxy、qianyeyue-affinity、sticker-cap、self-surf、stamina。新增可编译包中的原型补丁和未知协议动作仍须逐项验收。

本批次已进一步在隔离子进程检查全部93个可编译包的加载、启停及退出；详情和真实限制见 [全量离线检查](package-loading-audit-20261027.md)。不会读取旧会话或导入旧凭据来填补测试条件。该检查仍不算各包业务验收。

新增旧原包工作流：self-avatar查看与三种来源修改、quote-target生成途中插入消息后的原目标引用、quote-reply真实工具拦截、detailed-thinking运行记录、owner-identity按真实触发号码切换人设，以及scheduled-task独立唤醒、typing-indicator和msg-reaction协议工作流。主人设定保留会话模板及规则，同名、自称及历史消息不触发切换。状态卡原包测试现在位于tests/html-renderer.test.ts，与实际渲染测试顺序执行。

兼容钩子的 after-response 现在收到旧版完整 `response.message`，工具参数保留JSON字符串，触发批、主动标记和轮次按当前运行提供。展示性思考记录进入运行详情，不作为伪造聊天消息或下一轮模型输出。停用模块清理顶层定时器、请求及迟到结果，重启用创建全新实例；恢复继承也重算生命周期。

其中旧记忆插件必须接入确认后的三层记忆与可见性规则；不能复制一套旧记忆文件引擎绕过更正、优先级和隐私。原型补丁类插件需要对应的公共触发、发送或协议扩展点，不能只提供一个同名空壳。

## 媒体与模型补充

- 视频四模式的全部模式／模型／抽帧可用性／URL 组合与旧纯函数同输入对照。关闭画面仍可读元信息；auto 有视频专用模型时走原生，没有可用抽帧时明确退回元信息。元信息不会被描述成已看到画面。
- `video.frames` 使用公开服务桥按会话调用启用提供者。FFmpeg 实机、原生视频转码和 GIF 高级策略仍待补齐。
- 头像恢复数字 QQ 校验、协议端优先、腾讯备用地址和占位头像拒绝；所有下载继续经过受控网络层。
- 辅助模型调用保留显式模型、温度、输出上限、思考关闭、原始用量和finishReason。胶囊包的辅助调用进入独立操作并保存用量及计费；转换器进入对应会话作用域，显式端点不被账号池替换。其他管理器的后台模型调用和全部旧配额业务仍须继续验收。
- 运行完成后 RunContext 立即失效，延迟回调不能复用旧上下文发送；后台业务需创建独立受控运行。

## 搜索设置 API

全局设置页新增“搜索提供方”，支持旧提供方、自定义渠道、凭据掩码、React 抽屉与测试结果。自定义渠道重排后按 ID 保留密钥，不能按数组下标错配。

| 接口 | 行为 |
|---|---|
| GET /api/web/settings | 返回脱敏设置 |
| PATCH /api/web/settings | 局部更新；掩码保留原密钥；未提交字段保留 |
| POST /api/web/test | `{query}`；建立受控测试运行，返回 runId 与结果，不发送 QQ |
