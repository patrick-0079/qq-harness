## 会话目录

目录合并准入记录、独立配置、历史消息及管理元数据。添加会话或保存独立设置即获得准入，无需再维护白名单；全局黑名单和显式人工测试启动边界优先。移除会话仅撤销准入、独立配置与管理元数据，保留消息、记忆和运行历史。

名称依次使用管理别名、QQ 群名／好友备注／昵称、私聊消息中的姓名；未能取得名称时显示“未命名群聊／私聊”，号码在次要位置显示。名称缓存持久化，QQ 断线不清空；同一分钟的并发目录请求共享一次名称刷新。重命名使用 React 表单，留空恢复 QQ 名称，不修改 QQ 资料。

置顶会话单独分组，其余按首字母排序，中文采用拼音。支持字母定位、搜索、群聊／私聊、在线／屏蔽／配置状态过滤及分页。列表可拖动宽度并保存。

默认会话汇总尚未保存独立配置的会话。具体会话提供消息、运行／存档、记忆／笔记、统计、设置，以及插件贡献的工具和扩展页签。

## 设置与执行

人设与提示词、模型、记忆、聊天策略、工具与技能分区设置。会话保存完整快照，修改全局默认不会重写其有效值；可分区恢复或整会话恢复。记忆整理单独支持全局继承及稀疏覆盖。

一级“提示词管理”集中提供人设／提示词的新增、编辑、删除和搜索，默认人设只读；会话设置仅选择、Markdown预览，不内联改写文本。模型渠道在设置→模型接入维护，支持主／备用模型、超时、温度和思考参数。密钥集中保存且 API 仅回传存在标记，未提交密钥不会被清空；引用中的目录项不能删除。

私聊概率、群 @／关键词／普通消息概率、峰谷时段、跨午夜时段、活跃期、运行超时、未发言策略及指令禁言均接入实际执行。下线继续留档但不触发回复，上线不补发积压。人工发送和选中会话群发经过统一 outbound，目标与运行结果逐项显示。

统计包含收发、运行次数和时间、模型 Token／价格配置后的费用、工具调用、未回复原因和按日趋势。历史中未记录的指标显示不可用，不推算虚假值。

## 交互与主题

亮色、暗色、跟随系统三种主题，默认跟随系统；本地保存选择，系统变更实时生效。首屏前使用同源脚本应用主题，符合当前 CSP。表格、表单、日志、抽屉及内置 QQ/SnowLuma 页面统一使用主题变量。

重命名、笔记编辑、群发、删除、重置与未保存确认使用共享 React 弹窗。支持焦点限制、返回触发按钮、Esc／取消、输入校验、保存中及失败保留输入。轮询不替换正在编辑的内容；应用内离开或切换会话时提供 React 提醒。编辑抽屉隔离背景表单，避免操作落到背景输入框。

## 主要管理 API

| 接口                                | 行为                                      |
| ----------------------------------- | ----------------------------------------- |
| GET /api/chats                      | 合并目录、名称、准入及配置状态            |
| POST /api/chats                     | 添加准入，可指定别名                      |
| PATCH /api/chats/:chatKey           | alias、pinned、online、denied             |
| DELETE /api/chats/:chatKey          | 撤销准入与配置，保留历史                  |
| GET /api/chats/:chatKey/settings    | 生效设置                                  |
| PATCH /api/profiles/:chatKey        | 保存完整快照                              |
| POST /api/profiles/:chatKey/restore | 分区恢复，section 指定范围                |
| GET /api/chats/:chatKey/messages    | page、pageSize、query、senderId、from、to |
| GET /api/chats/:chatKey/stats       | 统计及缺失指标说明                        |
| GET /api/chats/:chatKey/export      | JSON 导出                                 |
| POST /api/chats/:chatKey/retry      | 重试处理                                  |
| POST /api/chats/send                | targets、text；逐目标运行结果             |
| GET /api/catalogs                   | 脱敏目录                                  |
| PUT /api/catalogs/:kind             | 替换指定目录，保留未提交密钥              |

记忆接口见 [memory-api.md](memory-api.md)。完整结构及依赖见 [系统图](system-map.md)、[逐插件依赖](plugin-dependencies.md)。
