# 控制台布局修整（2026-10-27）

本次修改仅在 `qq-harness`，针对侧栏折叠、表头异常、空间分配与小窗口可用性。业务、会话配置、扩展设置和现有数据保留。

## 已复现的原因

1. 侧栏文字的旧规则比“收起后隐藏”规则优先级高，收起后仍占空间；旧小屏布局还会将侧栏重新改成横向菜单。
2. 全局 `aside` 被赋予 `height:100vh` 和 sticky。便携QQ的操作指引也使用 aside，继承后整屏撑高，把目录设置挤到下一屏。
3. 插件表格使用自动列宽，长服务依赖占满横向空间，名称和版本被压窄，“激活1次”等短文本也逐字换行。
4. 全局 th 都 sticky，会话设置有多张表时表头堆叠。表格滚动、正文滚动和工作区滚动没有明确边界。
5. 会话面板最小590px、运行区最小560px，发送区还常驻一百多像素；窗口变小时内容只能继续向下挤。
6. 设置分区十多个按钮混在横向栏、表单多层重复padding，标题和帮助文案又占不同高度，实际编辑区被反复压缩。

## 布局规则

- 桌面主侧栏208px，收起64px，只有图标；自身滚动不挤压页面，连接状态和收起按钮固定底部。子菜单使用浮层定位，支持右方向键进入、Esc／左方向键返回；当前父菜单与子项正确高亮。
- 顶栏52px。页面标题紧凑排列，列表和会话使用剩余可用高度，不再靠固定大最小高度撑开。页面、目录、运行列表和详情分别滚动。
- 设置页分组表单采用三列，窗口较窄时两列或一列；标签和控件统一字号、边距及颜色。Ant Design容器色与全站主题一致，暗色按钮不再出现另一套黑底。
- 插件表格明确选择、开关、名称、状态、依赖和版本列宽，依赖按标签换行，长名称省略且保留完整title。扩展和工具表也声明关键列宽。表格不足宽时在表格内横向滚动，不挤碎表头。
- sticky表头只作用于表格自己的滚动容器。会话策略等多表表单的表头随内容滚动，禁止堆叠到同一位置。
- 会话目录、详情填满同一工作区；A–Z根据可用高度均分，不在较矮窗口丢掉末尾字母。发送栏压缩为单行输入与发送按钮，保留多行输入、准入和outbound语义。
- 会话设置在宽详情中使用144px分区导航，内容独立滚动、保存条固定底部；详情宽度小于620px时改成单行可滚动分区栏。
- 运行列表和详情共享剩余高度，过滤器、分页、发送区都保留可见位置。1920×1080、1366×768、1024×768均作几何断言。
- 便携QQ指引按实际内容高度布局，目录设置不再被整屏空白推走；SnowLuma设置和OneBot接入使用分栏表单；容器页明确运行配置、库存及命令区，开关与标签同一行，保存按钮不拉成巨大单元格。
- 小于700px时会话上下排列，各自保留可用高度并由页面纵向滚动；主菜单仍可收起，表格保持内部滚动。

主布局由 `apps/console/src/layout.css` 与 `sidebar.tsx` 管理。旧基础样式中 aside／nav／header 的布局选择器已限定到 shell；插件自身的语义标签不再冒充主导航。

## 验证

自动化使用隔离数据和mock QQ、SnowLuma、模型、网络，不向真实会话发送测试消息。新增 `tests/e2e/layout.spec.ts` 覆盖：

- 折叠的实际64px尺寸、图标和文字不越界、浮层在屏幕内、键盘、父菜单高亮、刷新持久化。
- 很长插件名称和依赖、列头与单元格横坐标和宽度对齐、表内滚动后的表头位置。
- 三种桌面尺寸的面板高度、保存按钮、表头滚离、运行区和发送区可见。
- 760px暗色与390px窄窗口，无文档横向溢出。
- QQ业务aside保持普通文档流和内容高度，目录表单首屏可达。

另对总览、插件、提示词、内置工具、扩展、QQ、SnowLuma以及五个设置子页，在1366px和900px下检查页面宽度、控件越界和脚本异常。完整批次结果和正式版本在发布后追加。
