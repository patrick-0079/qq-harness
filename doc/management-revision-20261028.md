## 已完成的需求

| 需求                          | 当前行为                                                                                                                                                                                                                 |
| ----------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 每轮回复条数上限              | 全局默认及会话覆盖，默认 5。文字拆分、媒体、文件、拍一拍及跨会话子运行共用物理发送额度。未知结果占额度，去重不重复占用；超额终止整轮并禁止重试。首次加载旧配置时旧 0 一次迁为 5，备份原配置；以后明确设置 0 仍表示不限。 |
| `send_message` 数组与控制标记 | `messages` 只接受字符串数组。每条自主使用 `⟦reply:消息ID⟧` 及多个 `⟦at:QQ号⟧`，允许同时引用和提及；每条只处理首个引用。后续引用及未知控制标记移除，Markdown 的 `#` 保持正文。                                            |
| @ 不生效、强制首条引用        | 转为原生 OneBot at/reply 段；任意数组元素可独立引用，提示词和旧扩展适配同步更新。真实协议回读已确认。                                                                                                                    |
| 仿生记忆插件无法删除          | 安装目录与配置 scope 分开识别；支持包在 plugins 而 scope=session 的情况。清理实时所有者、包及安装索引，重启不复活，保留业务存储。                                                                                        |
| 首次页面空白                  | 等待页面插件初始化；合并事件失效通知，避免重复取消查询；请求有超时、错误与重试。工具/目录加载时不伪装为空列表。                                                                                                          |
| 扩展文件选择按钮              | 样式化“选择 ZIP 或文件 / 选择文件夹”，原始 input 隐藏。                                                                                                                                                                  |
| 内置提示词删除与操作拥挤      | 内置人设和提示词只读，后端也禁止修改、删除和降级只读标志，可复制为自定义项。操作区域增加宽度及按钮间距。                                                                                                                 |
| 会话操作空间太小              | 去掉重复大标题；会话列表可折叠并持久化，运行列表可折叠，运行工作区可展开。空数据不显示空双栏，小窗口自动适配。                                                                                                           |
| 触发策略双套逻辑              | 去掉完整策略开关；配置边界适配旧配置，运行时仅一套判断。活跃期必触发；否则群聊依次判断 @/拍一拍、关键词、任意消息。关闭渠道继续，概率未命中结束；私聊使用独立概率。                                                      |
| 记忆展示与设置                | 会话“记忆”分管理/设置两个子页，再按短期、中期文档、长期文档、草稿本切换。                                                                                                                                                |
| 语义融合与演进                | 独立 Memory Agent 维护，短期/草稿为条目，中长期为主题 Markdown 文档。结合现有人设、记忆与来源决定融合、更正、遗忘；保留修订与来源，批量文档写入失败回滚。                                                                |
| 模型及用户的维护接口          | 对话模型提供检索、读取、申请、状态四类接口，用户也提交自然语言申请。受理返回任务 ID；支持待澄清、重试及重启恢复，受理时不宣称完成。                                                                                      |
| 人设作为长期记忆              | 初始模板形成可演进自我认知，影响记忆取舍。切换人设重新初始化，其他知识保留；旧任务不能写回旧人设。                                                                                                                       |
| personId 报错与错误界面       | 安全整数规范为字符串。任务展示可读失败原因、实际修改差异、补充说明及重试，不再将错误对象拆成零散标签。                                                                                                                   |
| 旧文本遗忘后复活              | 已迁移文本被遗忘后，GET 不回退旧文本；检索遵循有效状态。                                                                                                                                                                 |

示例：

```json
{
  "messages": [
    "第一条普通消息",
    "⟦reply:消息ID⟧第二条引用指定消息",
    "⟦reply:消息ID⟧⟦at:QQ号⟧第三条同时引用与提及"
  ]
}
```

记忆的数据结构、工具契约及部署边界见 [独立记忆 Agent 说明](memory-agent-20261028.md)。旧中长期保持层级及正文，增加文档元数据并保留历史；旧管理迁移脚本中的中长期降级流程不适用于本次升级。

## 指定会话真实联调

独立运行目录为 `var/live-management-1793122556759`；启动级 allowedChats 仅允许私聊 `10002` 和群聊 `10001`。

人工脚本 `tools/verify-management-live.ts --live` 只复用 OneBot 连接参数，不复制生产聊天记录、记忆或模型密钥，不启动/关闭用户 QQ。每个会话发送四条带联调标识的文本及一次拍一拍，第六次和后续文本在发送前被拦截。未调用收费模型。

10 项协议验收全部通过：普通第二条、第三条自主引用、群聊第四条同时引用与 @、控制标记隐藏、共享五条额度及超额拦截。get_msg 只回读本次合成消息；私聊引用段使用原消息 message_seq，已与原消息交叉核对。证据见 [真实协议结果](verification/management-live-20261028.json)。

没有修改生产配置、已有记忆或当前运行版本。3310 仍使用启动配置指定的原发布目录；最新构建位于 `dist`，尚未替换生产服务。
