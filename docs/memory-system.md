# 分层记忆插件

完整的使用、数据流、隐私与检索说明见 [分层记忆完整指南](memory-guide.md)；接口与参数见 [API 与 Agent 工具](memory-api.md)，故障恢复见 [运行手册](memory-operations.md)。

`agent-memory` 是独立 Cordis 插件。它提供 `MemoryService`、管理 API、Agent 工具和会话页签；停用时撤销这些贡献并清理后台计时器。`memory-index-lexical` 是可替换的检索提供器，应用装配可通过 `AppOptions.memoryIndex` 指定另一插件。插件只在提示词里给出查询指引，记忆正文由 Agent 调用 `memory_search` 时读取。

## 分层和边界

| 范围     | 短期                     | 中期                     | 长期                     |
| -------- | ------------------------ | ------------------------ | ------------------------ |
| 会话成员 | 当前会话中此人的近期消息 | 阶段性互动摘要           | 在此会话稳定的特征       |
| 会话     | 近期消息                 | 阶段性话题与约定         | 稳定的会话规则           |
| 人       | 不跨会话暴露原始消息     | 已确认、可共享的阶段特征 | 已确认、非私密的通用特征 |

短期消息保存在原消息存储中，不复制进记忆表或向量索引。中期默认 30 天到期、14 天新近度半衰期；长期不按时间删除，以最后确认时间按 90 天半衰期降低排序，保留最低权重。可见范围、准入、删除及到期先于排序检查。初始排序权重：相关性 40%、证据可靠性 25%、重要性 15%、新近度 15%、范围贴合度 5%。反复读取不增强事实；证据补充和人工修正才更新确认时间。

敏感信息仅限原会话。私聊内容不会自动提升为通用个人记忆。后台提炼只处理已准入的入站消息，每 5 分钟或 30 条聚批。处理游标持久化；失败不推进游标，重启后续处理。同一事实键的相同内容合并证据，冲突内容使旧版本退出召回并保留修订历史。

## 权威仓储与检索索引

`MemoryRepository` 是权威数据源，持久保存记录、修订、记事本、提炼游标、索引事件及每个索引提供器的检查点。默认 SQLite 实现放在 `harness.sqlite`；开发文件实现原子写入 `memory-system/store.json`。旧 `StorageService.memory/setMemory` 保持原位，新查询将旧文本投影为兼容记录，不复制正文。

`MemoryIndex` 只接收中长期记录的可重建投影：ID、修订号、检索文本、范围和敏感性标记；它提供 upsert、remove、search、rebuild、health。`EmbeddingProvider` 是独立契约，未来向量索引可使用它，而不改变仓储、Agent 工具或最终排序。索引写入事件与权威记录同步持久化，后台按修订号幂等消费。启动或更换提供器时重建索引；构建期间新写入由后续事件补齐。

`MemoryService` 先从仓储取得当前会话可见的候选 ID，再将 `allowedIds` 传给索引；索引只返回这些 ID 及归一化相关分数。服务随后重新读取权威记录，再次检查状态、到期、准入、会话、人员与跨会话可见范围。索引未就绪或查询失败时，退回仓储内的范围检索。删除后的旧索引命中不能恢复正文或越过权限检查。外部向量服务的允许范围需要另行显式配置；当前没有外部向量请求。

## Agent 工具与管理

`memory_search` 按当前运行绑定的会话查询，会返回相关中长期记录与最多 5 条近期消息；指定人员时要求其属于当前会话。`memory_remember/update/delete` 只允许 Agent 修改当前会话及成员记录。旧 `memory_query/append` 保持现有会话文本语义。管理端提供 `/api/memory/records`、`/api/memory/search`、`/api/memory/notes`、`/api/memory/status` 及修订历史；旧 `/api/chats/:chatKey/memory` 继续可用。

记事本按会话隔离，Agent 可增删查改并标记重要。默认最长保留 7 天，由会话设置 `scratchpadMaxDays` 覆盖；读取不续期，修改重置期限，到期删除。重要条目只有在关联了当前会话的来源消息时才整理成会话中期记忆。记事本本身不进入检索索引，也不单独产生通用个人事实。

## 测试与运维

相似实现、中文场景评测和训练数据边界见 [记忆评测与训练数据](./memory-evaluation.md)。

`tests/memory.test.ts` 覆盖两种仓储、权限、修订、索引故障、记事本和后台提炼；`tests/e2e/memory.spec.ts` 验证客户端页签与插件停用。SQLite 一致性备份包含权威记忆和索引事件；词面索引在内存中重建，不需要单独备份。若更换索引提供器，先用权威仓储全量构建并校验，再通过 `AppOptions.memoryIndex` 切换；失败时可换回词面提供器。
