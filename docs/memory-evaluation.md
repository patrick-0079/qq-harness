# 记忆评测与训练数据

这套记忆系统是**推理时的外部状态**：消息仍在原消息仓储，中长期事实在权威仓储，Agent 需要时调用工具读取。保存一个人的偏好不需要、也不应该训练模型权重。首版没有收集训练集、训练嵌入模型或微调提炼模型；现有自动提炼使用配置中的模型，单测只用 mock。

## 可参考的实现

- [Mem0 论文](https://arxiv.org/abs/2504.19413)采用提取、整合和检索流水线。本插件借鉴了候选事实与合并步骤，但保留原消息证据、修订和独立权威仓储，避免让检索索引承担事实真值。
- [Letta / MemGPT](https://docs.letta.com/guides/agents/memory/)区分可编辑的上下文记忆与外部召回记忆。本插件的记事本提供 Agent 可编辑的暂存空间，但不自动占用每轮上下文；只有明确的查询指引常驻提示词。
- [LangMem 概念指南](https://github.com/langchain-ai/langmem/blob/main/docs/docs/concepts/conceptual_guide.md)区分事实、经历与行为程序。本项目优先处理可核对的事实和阶段摘要；不会把观察到的个人习惯自动改写为 Agent 的全局行为规则。

这些方案的公开评测不能直接代表中文 QQ 群的效果。短句、口语、引用、多人同轮发言以及群内玩笑都会改变提炼的误报率，因此是否接入向量索引必须用本项目的评测数据决定。

## 数据用途与边界

| 用途           | 首选数据                                     | 是否需要真实聊天 |
| -------------- | -------------------------------------------- | ---------------- |
| 功能与权限测试 | 人工编写的合成会话和 mock 模型输出           | 不需要           |
| 提炼质量评测   | 获得明确许可的去标识化样本，人工标事实与来源 | 可选             |
| 检索与排序评测 | 合成及获许可样本的查询、相关记录、不可见记录 | 可选             |
| 模型微调       | 另行取得明确授权、评估必要性并建立删除机制   | 当前不做         |

真实 `source/data` 或其他部署存档不进入自动测试、公开基准、训练集或第三方向量服务。即使去掉 QQ 号，原话、时间和群内事件仍可能重新识别个人；样本应在授权范围内最小化保存，并单独限定访问和删除期限。外部嵌入模型是否能处理会话限定记忆，是未来提供器配置的独立决策。

## 样本和标注

评测样本建议用一个隔离的 JSONL 目录，每条用匿名会话与人员 ID、消息时间、消息本地 ID、文本、允许范围、查询时点表示。标注至少包含：

1. 候选事实的 `scope`、`tier`、`key`、正文、证据消息 ID、是否本人明确陈述、敏感性、置信度区间及到期或失效时间；无值得记忆的消息也要保留为空例。
2. 纠正关系：旧事实、新事实及哪条消息使旧项失效。把引用、反讽、代别人发言、相互矛盾和重复转发分别标出。
3. 查询的可见会话、当前发言者、目标人员、相关事实 ID、应拒绝的事实 ID、可回答文本及「证据不足」标签。包含同义改写和没有共享关键词的中文问法。
4. 记事本样本单独标注创建、修改、重要标记、来源、期限和期望提升结果，不把暂存内容直接视为已证实事实。

若用模型协助预标，人工必须复核证据和可见范围；模型生成的标签不能作为自己的无偏评测真值。划分训练、开发、测试时按**人员和会话整体隔离**，同时用早期消息构建记忆、较晚查询评测，避免同一事实或改写问题泄漏到不同集合。公开的 [LoCoMo](https://github.com/snap-research/locomo) 和 [LongMemEval](https://github.com/xiaowu0162/LongMemEval)可用于能力冒烟检查；本地中文样本用于决定产品改动。

## 评测顺序

1. **写入**：统计候选事实精确率、证据引用准确率、范围和敏感性误判、冲突更新正确率、重复处理后的事实数。跨会话隐私泄漏是阻断项，不能靠平均分抵消。
2. **召回**：固定同一权威仓储和同一可见候选集合，比较词面索引、可选的 FTS5、未来向量索引及混合索引的 Recall@8、MRR、无答案误命中和中文同义改写子集。分别报告会话、人、会话成员三类结果。
3. **回答**：让同一回答模型使用各检索方案，统计事实正确率、引用证据比例、拒答正确率、错误引用及上下文 token、提炼成本和 p95 延迟。检索分数提高不等于回答一定改善。
4. **衰减**：用时间推进测试 14 天和 90 天半衰期，检查新证据是否提升、仅重复读取是否保持不变、纠正后旧项是否退出结果。权重 40/25/15/15/5 是起点；仅在锁定测试集前，用开发集网格搜索或成对排序调整。

先记录词面基线与失败样本，再确定向量提供器的验收阈值。只有中文同义改写的召回及最终回答显著改善，且隐私、延迟和成本可接受时才切换索引。切换时对同一批权威记录全量构建新索引、核对 ID/修订和权限、并行评测，然后修改装配提供器；旧索引保留为回退路径。评测数据和任何未来训练数据的许可、保留期及删除流程应在使用前单独确认。
