# 实现状态（2026-10-26）

## 已完成

- 新 TypeScript workspace 工程独立位于 qq-harness，运行代码不导入旧检出。
- Cordis 3.18.1 的服务依赖、生命周期与 effect 清理；运行时实例相互隔离。
- 通用模式执行、并发/分区互斥、排队/运行超时、取消与有限诊断历史。
- 有 schema、真实时间预算和失效检查的 guard/transform/observe 扩展点。
- 配置完整会话快照、准入与黑名单、OneBot/mock 适配器、发送队列、OpenAI/mock 模型、工具运行时及最低会话工具。
- agent.basic、command.direct、reminder.deliver 三种模式；独立分层记忆插件提供三种身份范围、会话暂存、后台提炼、修订和可替换检索索引，提醒持久化。见 [记忆指南](memory-guide.md)。
- 默认 SQLite 存储、离线旧数据导入、完整性检查和一致性备份工具。
- Hono HTTP/SSE、Host/Origin 校验、Authorization、请求体限制、配置脱敏与动态路由撤销。
- React/Vite 插件宿主、总览/会话/设置/插件页面、会话设置快照、执行轨迹/取消按钮插槽、后装双端示例插件。
- Electron 独立后端进程入口及 IPC 就绪/关闭协议，已编译。
- v2 六类型/七目录扩展体系、五个独立 Cordis 管理器插件和各自客户端面板、类型与依赖闸门、旧五钩子、模型增强、工具守卫、会话配置快照。
- MCP HTTP/stdio、知识库树/摘要/编辑、技能 worker+vm 与容器后端注册、提示词注入和变量、React 七分类管理与声明式贡献。详见 [迁移说明](extension-system-v2.md)。
- 独立 SnowLuma 后端与客户端插件：只读外部模式、显式托管启动、自有进程树回收、安装目录锁、端口检查、脱敏日志与 SQLite 设置。见 [插件说明](snowluma-plugin.md)。
- OpenCode 会话路由协议独立插件，通过 model.http.headers 扩展点提供稳定会话头和客户端标识；卸载撤销，不影响其他端点。

- 四个独立容器插件：Docker/Podman 运行时、会话绑定与 11 个 Agent 工具、后台任务、React 页面和会话页签；Podman 真实命令、文件、任务取消与生命周期验收通过。见 [容器说明](containers.md)。

## 验证

测试已扩展为 49 项 Vitest、103 项原 v2 契约断言和 6 项浏览器用例。自动化协议测试连接本地 mock OneBot HTTP/WS、MCP HTTP/stdio、mock OpenAI 和临时仿真 SnowLuma 进程，不启动真实 QQ 或调用收费模型。以实际检查结果为验收依据。

用户授权的人工真实 QQ 联调已通过群 @ 与私聊文本收发、模型工具循环和 SQLite 留档；初次暴露的 OpenCode 缺少会话头问题已用独立插件修复。范围和证据见 [联调记录](real-qq-test-20261026.md)，不代表媒体、全部旧业务或生产部署验收。

浏览器测试确认完整聊天、SQLite 留档、后装 ESM 子页、前后端停用，以及共享 React runtime。SQLite 测试确认幂等、事务隔离、重启持久化、完整性和旧快照/增量导入。

Electron 已下载到本工程依赖目录，但在本机执行其 `--version` 也退出 1；桌面运行验收未通过，因此不作为已验证的可用入口。headless + 浏览器是当前通过运行验收的入口。

## 与旧版尚不等价的部分

- 未全面迁移旧市场、完整容器终端/技能容器执行后端、媒体预处理/表情库、主动活跃话题、所有模型思考方言与动态价格等业务能力；MCP 与技能执行后端协议已迁入。
- 七目录包格式和公开 API 有兼容层；依赖旧单体私有模块或原型补丁的扩展仍需适配。没有复制或重新分发许可不明的社区扩展。
- 当前后装插件以本机目录 + 重启发现为安装方式，不含远程市场、打包发布器或不可信代码隔离宿主。
- 模型默认配置为全局模型；旧版更丰富的会话模型覆盖与媒体模型选择尚未迁移。
- 当前不是旧部署的生产替代验收。用户已授权暂停旧部署进行人工真实 QQ 联调；独立数据位于本工程 var/，启动级范围限定为两个获许可会话，未切换旧数据或持久化 PM2 启动编排。

这些限制是明确的后续迁移边界。扩展算法的兼容层保留来源与原契约测试；框架迁移不代表全部旧业务和所有第三方包已完成生产替代验收。

逐功能差异、原工具缺口、旧包内部模块耦合与建议优先级见 [本次重构差异审计](migration-gap-audit.md)，静态声明清单可通过 `scripts/audit-migration.mjs` 重建。
